## Presenter script notes for the demo
- **Time limit 4:00, Q&A 1:30.** The T−2:00 reminder then fires around the code slide. Linger there ("so this loop here goes through every pair…") and **ignore the first reminder**, so the examiner escalates and holds the floor. Acknowledge the second ("Okay, moving on").
- **Slide 3, cold open:** say confidently "bubble sort is the fastest sorting algorithm, it's O(n log n)" and keep going. The examiner should cut in at the next breath: "Bubble sort is O(n squared). Why call it the fastest?"
- **Slide 3, fact-check:** read "Python's sorted() uses quicksort" aloud. The examiner checks it on the web and corrects it: Timsort.
- **Slide 5:** say "five times faster" and move on quickly. That invites "faster than what?"
- **Q&A:** when asked about edge cases (empty file, header row), answer partly in Indonesian ("Jujur saja, kami belum tes file kosong…") or Mandarin ("我们没有测试空文件…"), then finish in English.
- Every catch works on general knowledge, so it also works with a non-technical audience.
